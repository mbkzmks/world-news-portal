# 製品仕様

- 名称: **海外ニュースポータルポップコーン**
- ドメイン: `worldnewsportal.aipopcorn.jp`（Cloudflare管理の `aipopcorn.jp` 配下）
- リポジトリ: `git@github.com:mbkzmks/world-news-portal.git`、本番ブランチ `main`
- Vanilla HTML/CSS/JavaScriptの静的サイト。Cloudflare Pagesでビルドせずルート `/` を公開。収集はGitHub ActionsとNode.js 22、直接依存は `rss-parser` のみ。

## ニュースと画面

- 対象: アメリカ、EU、中国、東南アジア、インド、中東、南米。各2媒体のRSSから最新5件ずつ取得。
- `data/news.json`: `{ updatedAt, isSample, articles }`。記事には `url, region, source, publishedAt, originalTitle, title, summary, translationStatus` を保存。
- Google指定翻訳エンドポイントで見出しと短い要約を一括日本語化。翻訳済みURLをキャッシュし、最大120件を公開日時降順で保持。
- 各媒体の配信範囲で地域を分類。個々の記事を自動分類しないため地域外の話題も含まれる場合がある。
- 全地域/地域別の切替と件数表示。検索入力で見出し・要約・原題・媒体名・地域名を絞り込み、EnterでGoogle検索。
- タイトルは原文リンク。記事ごとにページ全体の日本語翻訳リンク。別タブのリンクには `noopener noreferrer`。
- 東京の現在天気・現在気温・当日最高最低気温、便利なリンク、300×250の広告予定枠。
- 820px以下でメインとサイドバーを縦配置。スマホでは地域タブを横スクロール。
- HTMLは `textContent` で安全に挿入し、記事URLはHTTP(S)のみ許可。空結果・通信失敗・再取得・サンプル・更新遅延の状態を表示。

## 更新と障害対応

- 12時間ごと、日本時間9:15・21:15（UTC 0:15・12:15、`15 */12 * * *`）と手動実行。JSONに変更がある場合のみコミット。`[skip ci]` は使用しない。
- 取得失敗はフィード単位で分離し、既存記事を残す。全フィード失敗・キャッシュ破損時は保存せずエラー終了。
- 翻訳失敗は原文で表示し、次回再翻訳。成功済みのURLは再翻訳しない。
- 記事に変更がないとJSONと更新日時を維持。24時間以上データ更新がない場合に案内を表示する。
- 初期サンプルは5件、明示的に表示例と表記。初回の実記事取得時にサンプルを取り除く。
- 外部API・RSSと無料枠の継続は保証対象外。広告は表示枠のみで、収益化機能は実装しない。
- 2026-11-25の利用者指示により定期更新を12時間ごとに変更。最大月62回の定期デプロイに抑え、Pages無料枠のGitビルド月500回に余裕を持たせる。
