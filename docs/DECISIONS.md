# 設計判断

## 2026-11-25 初期構築

- **Cloudflare Pages + GitHub Actionsを採用**: 指定の無料・静的運用を守る。Sites独自ホスティングやサーバー、追加フレームワークは使用しない。
- **Node.js 22とlockfileを使用**: Node.js 20以上の要件を満たし、組み込みfetch・タイムアウト・テストランナーで直接依存を `rss-parser` のみに保つ。
- **URL単位で成功翻訳を再利用、保持記事の失敗分を再試行**: RSSの最新5件から外れた原文も再翻訳する。保存対象120件を先に確定し、翻訳タイムアウト8秒で25分のワークフロー上限内に収める。
- **前回記事をマージして120件に制限、原子的に保存**: フィード障害や中断で公開JSONを空・破損状態にしない。全フィード失敗時は更新しない。
- **文字列のHTML組立を避けtextContentで描画**: RSS・翻訳由来のHTMLを実行せず、URLのHTTP(S)検証と併用してXSSを防ぐ。
- **翻訳の区切りは数値記号 `【771923】`**: 実APIで英単語入りの区切りが翻訳されることを確認。タイトルと要約を1リクエストのまま分離できる数値にする。
- **更新のないバッチはJSONを変更しない**: 不要なコミット・Pagesデプロイを避ける。更新日時はデータ変更時刻として扱う。
- **毎時更新は合意変更まで維持**: Pages無料枠のGitビルド月500回と毎時更新の最大744回に差がある。無断で頻度を落とさず、無料継続方針は利用者に確認する。
